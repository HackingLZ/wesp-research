# Changelog

## 0.2.0 - 2026-09-15

- Added bounded JSONL notification capture and generic decoding for all recovered families.
- Added repeatable WESP build/ETW schema harvesting and semantic build diffs.
- Expanded authorization probes and added current/credential/SYSTEM process orchestration.
- Added JSON rule DSL validation and versioned rule IR with a confirmed ProcessCreate adapter.
- Added ETL-to-CSV conversion and a self-contained correlated HTML timeline.
- Added optional Frida wire recording, symbolic pointer regions, validation, and gated replay.
- Added periodic integrity/availability heartbeats and offline health scoring.
- Expanded offline unit coverage from three to eleven tests.
- Added unattended offline, discovery, live-lifecycle, and optional wire validation harnesses.
- Recovered both manifestless WESP TraceLogging provider GUIDs and fixed multi-provider ETW capture.
- Recorded the build-29667 capability matrix, selector behavior, and property-support ranges.
- Added bounded health/state watchers, automated Frida recording duration, and a read-only polling consumer.
