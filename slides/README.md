# WESP HTML slide deck

Open `wesp-overview.html` in a browser. The deck is self-contained and requires no network access.

Controls:

- Right arrow, down arrow, Page Down, or Space: next slide
- Left arrow, up arrow, or Page Up: previous slide
- Home/End: first/last slide
- Swipe horizontally on touch devices
- Browser print: one 16:9 slide per page (17 slides total)

The URL hash records the current slide, so `wesp-overview.html#9` opens slide 9 directly.
